# Metrics and evidence

Host receipt/send times are perf_counter_ns: monotonic nanoseconds with a machine-local arbitrary origin. MCU times are unsigned monotonic microseconds since boot. Camera timestamps are original SDK milliseconds plus original domain. MCAP log_time/publish_time use host monotonic ns; no clock transform is substituted for a source time.

Statistics sort raw samples and interpolate linearly at position (n-1)*p. Report mean, min, max, p50, p95, p99; empty populations yield null. Rates are payload or wire bytes divided by observed elapsed seconds (H02 simulation uses requested virtual duration). Encoded USB counts can include command responses in physical captures and are labeled transport bytes; payload throughput counts only DATA. The default serial baud value is a CDC API setting, not the physical USB rate. Host interval observations can be identical when several packets arrive in one read.

Sequence analysis counts forward gaps, equal sequence duplicates, backward/out-of-order observations and boot-ID changes. uint32 rollover is allowed. Firmware generates a sequence before enqueue, so queue loss is detectable later and explicitly counted. Firmware counters are cumulative; H02 records before/after baselines and qualifies the change. Reset detection is separate from a gap.

The serial adapter also tracks boot IDs on command responses, so a reset appearing only in the final STOP/STATUS reply is still detected. Serial disconnection retains partial packet metrics and raw observations. Missing final counters prevent qualification; historical counters are never subtracted from an unavailable snapshot as if it contained zeros. CRC failures and total decoder errors are reported separately.

Clock fitting defines host midpoint x=(t1+t4)/2 and MCU midpoint y=(t2+t3)*500 ns. Sort by (t4-t1)-(t3-t2)*1000 and retain the lowest-RTT half, minimum four. Center the least-squares affine fit to reduce floating point cancellation. Drift ppm=(slope-1)*1e6; offset is y-x at a reported host reference, not a timeless constant. Report residual distribution, rejection count and round-trip distribution. Delay asymmetry and physical event uncertainty remain unknown. Simulation reports known drift/offset and estimation errors separately.

Every run writes metadata (complete flag, UTC start/end, version), exact requested configuration, environment, summary, Markdown report, logs and checksums. Measurement CSV exists only when observations exist. Serial tests save binary bytes; H03 saves camera capabilities and metadata, with raw pixels only if requested. MCAP messages keep format, stride, dimensions, frame number, source timestamp/domain, host timestamp, intrinsics/depth scale and unmodified raw pixels as base64. Schema identifies provenance. Per-topic incoming/recorded/read-back counts must agree.

Run wall duration includes reporting/capture overhead and can differ from requested capture duration. Writer latency measures add_message call duration (plus injected delay if requested), not an isolated storage device benchmark; finalization includes flush/fsync and full verification. Queue maximum occupancy measures queued serialized bytes, not process memory. CPU and memory are opportunistic host process metrics, not system-wide counters. Hashes use streaming SHA-256 over original files. Missing outputs must never be reconstructed as fabricated measurements.

Writer output bytes/second divides finalized MCAP bytes by the recorder lifetime, including producer waiting and verification. It describes this experimental pipeline, not isolated disk speed or a future Rust writer's capacity.

PASS is scoped to the implemented experiment criteria in 05_TEST_PROCEDURES. FAIL includes expected fault-injection failures. BLOCKED includes CONFIG, HARDWARE, STORAGE and SETUP reasons. SIMULATED_PASS is never physical qualification. NOT_RUN is used for deliberately unattempted discovery/procedures. Combined status gives FAIL priority over BLOCKED, then SIMULATED_PASS/PASS. Analyze verifies existing evidence and displays statuses; it does not recompute scientific metrics or modify raw measurements.
